AdTech Revenue Intelligence · End-to-end ML system

One feature pipeline. Three production models. A full view of the funnel.

AdCore-ML turns raw impression-level ad data into revenue forecasts, click predictions, and audience segments — with the data-quality and explainability work a real ad platform team would expect to see, not just a model score.

01 — Data

150k raw records, cleaned with a real validation pipeline

The synthetic generator intentionally injects missing values, sign errors, duplicate rows, and impossible funnel values (clicks > impressions) — then the pipeline below finds and fixes them.

Issues detected in raw data

Missing values by column

02 — Model A

Revenue forecasting

Three regressors, same feature set: a linear baseline, Random Forest, and XGBoost. We compare on MAE first — R² alone is misleading on right-skewed ad revenue.

03 — Model B

Click-through prediction

Will this impression convert to a click? Logistic Regression sets the floor; XGBoost is scored on ROC-AUC, calibration and log-loss — because a CTR system that ranks well but reports overconfident probabilities will misprice every auction.

ROC curve

Calibration: predicted vs. observed

04 — Model C

Audience segmentation

K-Means over behavioural features (session duration, CTR, CVR, revenue, content affinity). K was chosen with the elbow method and confirmed with silhouette score before profiling each segment in business language.
